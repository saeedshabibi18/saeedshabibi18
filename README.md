### ⛅ [Flask Weather App — CI/CD Pipeline with Docker, GitHub Actions & AWS EC2](https://github.com/saeedshabibi18/weather-application)
> Built and deployed a production-grade Flask Weather Application with a complete 3-stage CI/CD pipeline.
> Every push to GitHub automatically tests, builds, and deploys the app to AWS EC2 — zero manual steps.
>
> **Pipeline Stages:**
> - ✅ Stage 1 — Automated testing (health check + route validation)
> - ✅ Stage 2 — Multi-stage Docker build & push to Docker Hub
> - ✅ Stage 3 — Auto deploy to AWS EC2 via SSH with health verification
>
> **Highlights:**
> - Reduced Docker image size by 60% using Alpine Linux multi-stage build
